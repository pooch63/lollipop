<h1 align="center">Lollipop</h1>

<p align="center">
  Bipartite graphs, made sweet.
  <br />
  <a href="https://lollipop.sh"><strong>lollipop.sh</strong></a>
</p>

---

Most graph algorithms are written once, then left alone. Lollipop keeps the search running.

It plants a known answer in a bipartite graph, asks an agent for a short program, and scores what comes back. Programs that recover more of the answer, with work that stays in proportion to the graph, are kept. Then it tries again. Reductions, heuristics, and exact checks share one bench, so a new idea has to beat the last one on the same graphs, the same grid, and the same budget.

Watch a run at **[lollipop.sh](https://lollipop.sh)**.
